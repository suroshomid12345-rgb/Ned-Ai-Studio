# Ned_Ai Studio

مرکز مدیریت پروژه‌های تولید محتوای هوش مصنوعی برای YouTube و TikTok.

## ساختار پروژه

- `01_Ideas_and_Scripts/` — ایده‌ها، تحقیق ترندها و سناریوها
- `02_Prompts_and_Assets/` — پرامپت‌ها، تصاویر مرجع و فایل‌های گرافیکی
- `03_Video_Projects/` — پروژه‌های ویدیویی و خروجی‌های تدوین
- `04_Blender_Animation/` — فایل‌ها و اسکریپت‌های انیمیشن Blender
- `05_Audio_and_Voice/` — صداگذاری، گویندگی و موسیقی مجاز
- `06_Thumbnails_and_Metadata/` — تامبنیل، عنوان، توضیحات و هشتگ‌ها
- `07_Automation_and_Tools/` — اسکریپت‌ها و تنظیمات اتوماسیون
- `08_Publishing_and_Analytics/` — برنامه نشر و گزارش عملکرد

## اصول کار

- اولویت با ابزارها و روش‌های رایگان است.
- هیچ هزینه یا اعتبار پولی بدون تأیید قبلی مصرف نشود.
- انتشار و حذف محتوا فقط با اجازه صریح انجام شود.
- رمز عبور و کد تأیید در این مخزن ذخیره نشود.
- فایل‌های حجیم ویدیو و خروجی‌های نهایی را در Git ذخیره نکنید؛ از فضای ذخیره‌سازی مناسب استفاده کنید.

زبان محتوا می‌تواند دری و انگلیسی باشد.
